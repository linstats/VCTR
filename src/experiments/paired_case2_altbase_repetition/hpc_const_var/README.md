# Case 2 HPC 结果总结

这个目录保存 `paired_case2_altbase_repetition` 的 HPC 汇总结果。

## 实验配置

- 模型：paired Case 2 altbase，varying `\sigma^2(t)`
- 样本量：`n = 2000, 5000`
- 系数函数：`base1, base2, base3, base4`
- 相关系数：`\rho = 0.0, 0.3, 0.6, 0.9`
- 重复次数：每个 `(n, coef, rho)` 组合 `30` 次
- 降维配置：`R = 3`, `S = 27`, `p0 = 4`
- 真值参数：`\beta = (2.0, 1.0, -1.0, 0.5)`, `\sigma^2 = 1.0`
- 协方差模式：`exchangeable_varying_sigma`
- 带宽：`signal_bandwidth = 0.20`, `variance_bandwidth = 0.20`
- 数值稳定：`ridge = 1e-4`
- 并行：`n_jobs = 12`
- HPC 提交方式：最初拆成 `10` 个 part；其中 `part1` 到 `part8` 先生成旧快照、审计缺口，再做 exact backfill；`part9` 和 `part10` 直接完整跑完；最终合并后共有 `960` 个 successful fits

## 文件说明

- `hpc_10_parts/`：原始 `part1` 到 `part10` 输出、旧快照、新快照，以及 backfill / merge 脚本副本
- `results/raw_results.csv`：最终合并后的逐次结果
- `results/summary_results.csv`：最终合并后的汇总结果
- `provenance.csv`：每条合并结果的来源映射
- `merge_meta.json`：合并元数据
