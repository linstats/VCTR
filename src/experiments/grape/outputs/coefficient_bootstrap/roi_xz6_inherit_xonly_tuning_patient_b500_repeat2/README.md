# ROI X+Z6 patient-bootstrap repeat2

Independent-seed (`20260805`) repetition of the ROI `B=500` patient-cluster
bootstrap pilot. Model tuning and preprocessing are identical to
`roi_xz6_inherit_xonly_tuning_patient_b500`; only the bootstrap seed and run
identity differ.

This directory contains the complete six-variable beta table, coefficient and
variance summaries, aggregation metadata, and the ROI `A(t)` and `sigma(t)`
figures. It is a Monte Carlo repeatability check, not final manuscript
inference.
