# Case 1 HPC 结果总结

这个目录保存 `paired_case1_altbase_repetition` 的 HPC 汇总结果。

## 实验配置

- 模型：paired Case 1 altbase，varying `\sigma^2(t)`
- 样本量：`n = 1000, 2000`
- 系数函数：`base1, base2, base3, base4`
- 相关系数：`\rho = 0.0, 0.3, 0.6, 0.9`
- 重复次数：每个 `(n, coef, rho)` 组合 `30` 次
- 降维配置：`R = 4`, `S = 25`, `p0 = 4`
- 真值参数：`\beta = (2.0, 1.0, -1.0, 0.5)`, `\sigma^2 = 1.0`
- 协方差模式：`exchangeable_varying_sigma`
- 带宽：`signal_bandwidth = 0.18`, `variance_bandwidth = 0.18`
- 数值稳定：`ridge = 1e-4`
- 并行：`n_jobs = 12`
- HPC 提交方式：拆成 `10` 个 part；每个 part `3` 个 repetitions；总计 `960` 个 successful fits

## 文件说明

- `hpc_10_parts/`：10 个 HPC part 的原始输出
- `results/raw_results.csv`：合并后的逐次结果
- `results/summary_results.csv`：合并后的汇总结果
- `run_config.json`：本次 HPC 合并运行配置
- `merge_meta.json`：合并元数据
